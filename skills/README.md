## Where the files live

Imported skills stay under [`upstreams/<author>/`](../upstreams/) so Git can merge updates from their original repositories with local customizations. Edit those files in place; the links above open the actual local copies.

Add your own original skills beside this catalog at `skills/<skill-name>/SKILL.md`.

For [Skillshare setup](../docs/skillshare.md), point `sources.skills` at the **repository root**, not this `skills/` folder. The root [`.skillignore`](../.skillignore) selects the inventory for discovery.
